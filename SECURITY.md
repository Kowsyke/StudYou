# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a potential security vulnerability within StudYou, please report it responsibly.

1. Do not open a public GitHub issue for security vulnerabilities.
2. Email security concerns directly to the project maintainers.
3. Include detailed steps to reproduce the issue and potential impact assessment.

We aim to acknowledge receipt of vulnerability reports within 48 hours and provide updates until resolution.
